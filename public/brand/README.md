# Custom Apparel — brand assets

## The mark

The motif is the face of a **single jersey knit**: columns of interlocking
loops. It is the literal structure of the fabric this unit makes, not a
generic abstract shape. Six loops in the master mark, two in the favicon.

## Files

| File | Use |
|---|---|
| `logo-horizontal.svg` | Default lockup. Light backgrounds. Website header, letterhead, invoices. |
| `logo-horizontal-light.svg` | Same lockup for dark backgrounds. |
| `logo-stacked.svg` | Square-ish spaces — social avatars, stamps, packaging stickers. |
| `mark.svg` | Mark alone. Use at 32px and above. |
| `favicon.svg` | Browser tab, app icon. Simplified to two loops — the six-loop mark turns to mud below 24px. |

## Colours

| Token | Hex | Use |
|---|---|---|
| Navy 900 | `#071528` | Mark background, dark sections |
| Navy 800 | `#0b1f3a` | Headings, primary buttons |
| Navy 700 | `#122d50` | Gradient top |
| Gold 500 | `#c8a24a` | The loops, accents, primary CTA |

| Sand 50 | `#faf9f6` | Page background |
| Ink 500 | `#5b6270` | Body text |

## Clear space and minimum size

Keep clear space equal to the height of one loop on all sides. Minimum
reproduction width for the horizontal lockup is **120px** on screen / 32mm in
print. Below that, use the mark alone.

## Do not

- Recolour the loops to anything other than gold on navy, or navy on light
- Stretch, rotate or add effects (shadow, bevel, outline) to the mark
- Place the dark lockup on a busy photograph — use `logo-horizontal-light.svg`
  over a darkened image instead
- Re-typeset the wordmark in a different family

## Before sending to a printer

The wordmark uses live `<text>` with an Inter / Helvetica fallback. **Convert
text to outlines** before handing files to a press or a signage vendor, or
they will substitute a font. The mark itself is pure geometry and needs no
conversion.
